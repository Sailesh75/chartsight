    How it works

    1. De-identifyFind and redact names, IDs, dates and phone numbers.
    2. ExtractClaude on Amazon Bedrock returns each condition with its verbatim evidence.
    3. GroundBM25 retrieves real candidate codes; the model must choose from them.
    4. VerifyEvery code is checked against the official FY2026 ICD-10-CM set.
    5. ValueHCCs come from the CMS crosswalk; the RAF matches CMS's own software.
    Synthetic data only. No real PHI.
